CSV ROW — paste into farroadgambitconditions.csv
A status effect is a MECHANIC, not content — there is no CSV for it. Every one of the 14 shipped effects (sundered, frail, enfeebled, dulled, slowed, blinded, burning, hasted, warded, taunted, surging, bracing, regen, blurred) is a fixed-magnitude, timer-gated flag (u.st[id] counts down to 0) wired into exactly one small hook in src/farroad-core.js. This tab doesn't write code — it gets your new effect into the same shape as the shipped ones, checks its magnitude against real numbers already in the game, and outputs an implementation spec you hand back the way you'd hand back a CSV row. There's no support here for a variable-intensity or stacking effect (charge stacks are the one exception, and that's a separate system) — if what you want doesn't fit "on/off for N turns", say so and it needs a real design pass first, not just this tab.
